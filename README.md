# Case Studies

A collection of technical investigations, experiments and reverse-engineering projects.

## Case studies so far

### [iQIYI 4K DASH](iqiyi-4k-dash/)

Investigation into iQIYI's 4K DASH delivery, including its manifest structure, HTTP response behavior and compatibility with N_m3u8DL-RE.
Includes our findings, workflow diagrams and Python scripts for reproducing the investigation.


### [Better DST](better-dst/)

Investigation into automating DeepL's web interface for SRT subtitle translation using Python and Playwright, without directly calling the official DeepL API.

Covers subtitle cue integrity, batching, error recovery and browser automation, including our findings and workflow diagram. The source code is available in the [Better DST repository](https://github.com/slappepolsen/better-dst/).
